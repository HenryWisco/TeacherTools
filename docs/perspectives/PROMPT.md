# Prompt given to each AI reviewer

You are reviewing a new free website for teachers before it launches, to say how it could be made the best it can be.

**The product.** "Supply Closet" is a free website, no sign-up, where a teacher describes what they need and gets a print-ready classroom document in seconds. It has:
- A home page with a free-form "What do you need?" box (plus optional grade and subject).
- 24 fill-in-the-form tools: lesson plan, unit plan, sub plan, slide outline, worksheet, math word problems, vocabulary list, bell ringers, choice board, lab activity, quiz, exit ticket, rubric, study guide, reading passage + questions, text leveler, writing prompts, discussion questions, project idea, family email, report card comments, IEP goal ideas, differentiation ideas.
- Output is text only (headings, numbered questions, tables, underscore blanks; no images or diagrams), streamed onto the page. Actions: print / save as PDF (answer key on its own page), download for Word, copy into Google Docs, edit the text, ask for a revision, share to the public library.
- A public library of 27 starter resources (K-12), browsable by grade band, subject and type, with search. Teacher-shared documents appear after the owner reviews them.
- It is US-oriented (grades K-12, optional free-text standards code such as CCSS). English only unless the teacher asks otherwise in the request.
- No accounts, so nothing is saved between visits except in the browser. Daily limit of 40 documents per network.
- It is paid for by quiet display ads on the site (never on printouts), Amazon affiliate links to classroom supplies, a weekly email with a sponsor, and an optional "supporter" payment whose only perk is no ads. There is no paywall. It runs on a small, cheap AI model because ad income only covers about a tenth of a cent per document.
- It is built and run by one person.

**The people.** Below are 20 people who would use it.

{{PERSONAS}}

**Your job.**
1. For each of the 20 people, in 3-5 sentences: what would make them love this site, what would make them leave within a minute, and the single change that would matter most to them. Be concrete and honest; if the site as described fails them, say so.
2. Then give your own judgement: the 10 changes that would most improve the site, ranked, counting how many of the 20 people each one helps and weighing how hard it is for one person to build and whether it fits the "free, ad-funded, cheap model, no paywall" constraint. For each: what to build, who it helps, effort (small / medium / large), and any risk.
3. Name up to 3 things the site should deliberately NOT do, and which of the 20 people it should accept losing.
4. Say what you think the owner is most likely wrong about.

Do not flatter. Disagree with the product's assumptions where you think they are wrong.
