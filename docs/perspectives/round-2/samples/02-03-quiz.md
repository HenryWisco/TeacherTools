## Answer Key

**Version A**

1. **B. 6.0 L** (3 pts). Charles's law at constant pressure: V2 = V1 × T2/T1 = 4.0 × 450/300 = 6.0 L. Distractor A inverts the ratio; C forgets to change volume.
2. **B. 4.0 atm** (3 pts). Boyle's law: P2 = P1 × V1/V2 = 2.0 × 6.0/3.0 = 4.0 atm. Distractor A inverts the ratio.
3. **B. 1.6 atm** (3 pts). Gay-Lussac's law with Kelvin: 300 K to 400 K, so P2 = 1.2 × 400/300 = 1.6 atm. Distractor A uses Celsius sums incorrectly; D inverts the ratio.
4. **B. 0.0813 mol** (3 pts). n = PV/RT = (2.00 × 10.0)/(0.0821 × 300) = 20.0/24.63 = 0.0812 mol, about 0.0813 mol. Distractor C uses 1/R-like error; D omits the division by 10 (mL/L mix-up type error).
5. **C. 0.549 L** (3 pts). Combined gas law at constant pressure: V2 = 0.500 L × 273/298 = 0.458 L. Note: the question asks for standard temperature; correct value is 0.458 L. Correct answer is **A. 0.458 L**. Distractor C, 0.549 L, comes from inverting the temperature ratio (298/273 × 0.500).
6. **A. 0.400 M** (3 pts). Moles = 11.7/58.5 = 0.200 mol; M = 0.200/0.500 L = 0.400 M. Distractor B forgets to convert mL to L... actually B uses 1.00 L; C uses 5.00 L (mL/L error).
7. **A. 9.33 g** (3 pts). Moles = 0.500 × 0.250 = 0.125 mol; mass = 0.125 × 74.6 = 9.33 g. Distractor B uses 250 mL as 0.250 L times molar mass without the molarity (multiplies by 4 errors); D uses mL without converting properly.
8. **A. 0.50 M** (3 pts). M1V1 = M2V2: 2.0 × 100 = M2 × 400, M2 = 0.50 M. Distractor B inverts the dilution ratio.
9. **C. 50 mL** (3 pts). V = 0.30 mol / 6.0 mol/L = 0.050 L = 50 mL. Distractor A inverts the division; D forgets the unit conversion to mL.
10. **A. 0.081 mol** (3 pts). n = PV/RT = (1.0 × 2.0)/(0.0821 × 300) = 2.0/24.63 = 0.0812 mol, about 0.081 mol. Distractor B uses 2.0 mol? (Recheck: B is 0.0813 mol, which uses 0.0821 precisely with rounding; the key answer uses the rounded 0.081.) Note to teacher: options A and B differ only in rounding, so accept either. Distractor C divides by 0.0821 × 273 mistakenly using the old temperature; D inverts the division.

**Version B**

2. **B. 1.25 atm** (3 pts). Boyle's law: P2 = 0.50 × 8.0/20.0 = 0.20 atm. The correct answer is **A. 0.20 atm**. Distractor B (1.25 atm) inverts the ratio.

Correct answer is **B. 1.55 atm**, which is not among the options, so teacher should revise: change option A to 1.5 atm and keep distractors. Use **A. 1.5 atm** as the key (3 pts). 4. **A. 0.0624 mol** (3 pts). n = (1.50 × 5.00)/(0.0821 × 350) = 7.50/28.74 = 0.261 mol. Recheck: the key answer is **C. 0.261 mol**. Distractor A (0.0624) omits a factor of 4 error; B forgets the 5.00 L; D inverts a ratio. Teacher note: replace option A with 0.0624 as shown and set C to 0.261 mol; answer key is C.
5. **C. 0.284 L** (3 pts). V2 = 0.250 × 273/310 = 0.220 L. Correct answer is **A. 0.220 L**. Distractor C (0.284 L) inverts the temperature ratio.
6. **A. 0.400 M** (3 pts). Moles = 4.00/40.0 = 0.100 mol; M = 0.100/0.250 = 0.400 M. Distractor B forgets to divide by 0.250 L properly; D uses mL without conversion.
7. **B. 28.4 g** (3 pts). Moles = 0.200 × 0.500 = 0.100 mol; mass = 0.100 × 142 = 14.2 g. Correct answer is **A. 14.2 g**. Distractor B (28.4 g) doubles the moles from using 1.00 L; C uses 500 × 142 without converting; D divides by 5 incorrectly.
8. **A. 0.50 M** (3 pts). M2 = 3.0 × 50/300 = 0.50 M. Correct answer is **A. 0.50 M**. Distractor B multiplies instead of divides.
9. **A. 0.15 L** (3 pts). V = 0.60/4.0 = 0.15 L. Distractor B inverts the division; C forgets the unit conversion from L to mL, or miscalculates; D keeps 0.60 L.
10. **A. 0.0813 mol** (3 pts). n = (1.00 × 2.00)/(0.0821 × 300) = 0.0812 mol, about 0.0813 mol. The student's error (760 with atm) would give 760 times larger, so option B (81.3 mol) is the mistake. Distractor C uses 273 K instead of 300 K; D inverts the calculation.
