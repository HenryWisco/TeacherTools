## Worked Example

Problem: How many grams of water form when 4.00 g of hydrogen gas reacts completely with excess oxygen? The balanced equation is 2 H2 + O2 -> 2 H2O.

Solution:
- Moles of H2 = 4.00 g / 2.02 g/mol = 1.98 mol H2
- Mole ratio H2O : H2 = 2 : 2 = 1 : 1, so moles of H2O = 1.98 mol
- Mass of H2O = 1.98 mol x 18.02 g/mol = 35.7 g H2O

## Answer Key

1. Moles NH3 = 85.0 g / 17.03 g/mol = 4.99 mol NH3. Mole ratio N2 : NH3 = 1 : 2, so moles N2 = 4.99 / 2 = 2.495 mol N2. Mass N2 = 2.495 mol x 28.02 g/mol = 69.9 g N2 (about 69.9 g; keep 3 sig figs, since 85.0 g has 3).

2. Moles Al = 5.40 g / 26.98 g/mol = 0.2001 mol Al. Moles HCl needed for 0.2001 mol Al = 0.2001 x 3 = 0.6004 mol HCl; only 0.250 mol HCl is available, so HCl is limiting. Moles H2 = 0.250 mol HCl x (3 mol H2 / 6 mol HCl) = 0.125 mol H2. Volume = 0.125 mol x 22.4 L/mol = 2.80 L H2.

3. Moles Fe2O3 = 500. g / 159.7 g/mol = 3.130 mol. Theoretical moles Fe = 3.130 x 2 = 6.261 mol. Theoretical mass Fe = 6.261 mol x 55.85 g/mol = 349.7 g Fe. Percent yield = 292 g / 349.7 g x 100 = 83.5%.

4. Moles CaCO3 = 25.0 g / 100.09 g/mol = 0.2498 mol. Mole ratio CaCO3 : CaO = 1 : 1, so theoretical moles CaO = 0.2498 mol. Theoretical mass CaO = 0.2498 mol x 56.08 g/mol = 14.0 g CaO. Percent yield = 9.80 g / 14.0 g x 100 = 70.0%.

5. Moles NaOH = 0.250 mol/L x 0.5000 L = 0.1250 mol. Mass = 0.1250 mol x 40.00 g/mol = 5.000 g NaOH.

6. M1 V1 = M2 V2: (12.0 M)(V1) = (0.100 M)(250.0 mL). V1 = 25.0000/12.0 = 2.08 mL stock solution (about 2.08 mL; 3 sig figs).

7. Moles NaOH = 0.1500 mol/L x 0.03120 L = 4.680 x 10^-3 mol NaOH. Moles H2SO4 = 4.680 x 10^-3 / 2 = 2.340 x 10^-3 mol. Molarity H2SO4 = 2.340 x 10^-3 mol / 0.02500 L = 0.09360 M H2SO4.

8. Combined gas law: V2 = V1 x (P1/P2) x (T2/T1) = 4.80 L x (1.00 atm / 2.00 atm) x (450. K / 300. K) = 4.80 x 0.500 x 1.50 = 3.60 L.

9. Convert T = 27.0 + 273.15 = 300.2 K (use 300. K for 3 sig figs). P = nRT/V = (0.400 mol)(0.0821 L atm/mol K)(300. K) / 2.50 L = 3.94 atm.

10. Moles He = 3.00 g / 4.00 g/mol = 0.750 mol. T1 = 25.0 + 273.15 = 298.2 K (use 298. K). V1 = nRT/P = (0.750)(0.0821)(298.)/1.10 L = 16.7 L. Then V2 = V1 x (T2/T1) at constant pressure: T2 = 35.0 + 273.15 = 308.2 K (use 308. K). V2 = 16.7 L x (308./298.) = 17.3 L. Note: the first volume is 16.7 L (3 sig figs) and the new volume is 17.3 L.
