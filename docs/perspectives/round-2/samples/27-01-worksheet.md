## Answer Key

1. (x + 3)(x + 4) = 0, so x = -3 or x = -4.

2. (x - 4)(x - 5) = 0, so x = 4 or x = 5.

3. (x - 4)(x + 3) = 0, so x = 4 or x = -3.

4. (2x + 1)(x + 3) = 0, so x = -1/2 or x = -3.
Check: 2x^2 + 6x + x + 3 = 2x^2 + 7x + 3. Correct.

5. (x - 4)(x + 4) = 0, so x = 4 or x = -4.

6. 3x(x - 4) = 0, so x = 0 or x = 4.

7. a = 1, b = 4, c = -1. Discriminant = 16 + 4 = 20.
x = (-4 ± sqrt(20)) / 2 = (-4 ± 2 sqrt(5)) / 2 = -2 ± sqrt(5).
So x = -2 + sqrt(5) or x = -2 - sqrt(5).

8. a = 2, b = -3, c = -5. Discriminant = 9 + 40 = 49.
x = (3 ± 7) / 4, so x = 10/4 = 5/2 or x = -4/4 = -1.
(This equation also factors as (2x - 5)(x + 1) = 0.)

9. a = 1, b = 6, c = 10. Discriminant = 36 - 40 = -4. Since the discriminant is negative, there are no real solutions. (Over the complex numbers, x = -3 ± i.)

10. Let w be the width. Length = w + 3. Then w(w + 3) = 40, so w^2 + 3w - 40 = 0, which factors as (w + 8)(w - 5) = 0. Since width must be positive, w = 5 meters. Length = 8 meters.
