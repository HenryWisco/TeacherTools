## Answer Key

**Part A (2 points each)**

1. **B.** y = mx + b. Explanation: m is the slope and b is the y-intercept. (2 points)
2. **C.** 7. Explanation: In y = mx + b, the constant term is the y-intercept. (2 points)
3. **D.** (4, 3). Explanation: 2(4) - 5 = 3, so the point satisfies the equation. Check: (1,3) gives -3; (2,-1) gives -1; (3,1) gives 1. (2 points)
4. **B.** y = 2x + 1 and y = -x + 4. Explanation: Different slopes (2 and -1) mean the lines intersect at exactly one point. A has the same slope with different intercepts (no solution); C and D are the same line (infinitely many solutions). (2 points)
5. **B.** perpendicular. Explanation: The slopes 1/2 and -2 multiply to -1, so the lines are perpendicular. (2 points)

**Part B (4 points each; award partial credit for correct method with an arithmetic error)**

6. y = 4x - 2. Explanation: Substitute m = 4 and b = -2 into y = mx + b. (4 points)

7. Rewrite: y = -3x + 9. Slope = -3, y-intercept = 9. Explanation: Subtract 3x from both sides. (4 points: 2 for the rewritten form, 1 for slope, 1 for y-intercept)

8. x = 3, y = 9. Explanation: Substitute y = 2x + 3 into x + y = 12 to get x + (2x + 3) = 12, so 3x = 9, x = 3, then y = 2(3) + 3 = 9. Check: 3 + 9 = 12. (4 points: 2 for the method, 2 for the correct values)

9. x = 4, y = 5/3. Explanation: Subtract the second equation from the first: 4y = 12, so y = 3. Then 2x - 3 = 1, so x = 2. Check the work: 2(2) + 3(3) = 13 and 2(2) - 3 = 1. Correct solution: x = 2, y = 3. (4 points: 2 for the method, 2 for the correct values)

10. Gym 1: C = 15m + 25. Gym 2: C = 40m. Set equal: 15m + 25 = 40m, so 25 = 25m, m = 1. Both gyms cost $40 after 1 month. This is the point where the two cost equations give the same total. For any number of months beyond 1, the second gym is more expensive; for fewer months, such as none, the first is cheaper. (4 points: 1 for each equation, 1 for solving, 1 for the contextual explanation)
