# Counting and Writing Rhythms in 4/4

**Name:** ______________________  **Date:** ____________

Directions: In 4/4 time, there are four beats in each measure, and a quarter note gets one beat. Read each question carefully. Where a rhythm is shown, it is written in words and syllables, since this sheet is printed without a staff. Imagine the staff: each measure holds exactly 4 beats.

Rhythm reference (beats each note or rest gets in 4/4):

| Symbol name | Syllable | Beats |
|---|---|---|
| Whole note | ta-ta-ta-ta (held) | 4 |
| Half note | ta-ta (held) | 2 |
| Quarter note | ta | 1 |
| Eighth note | ti-ti | 1/2 |
| Whole rest | silent measure | 4 |
| Half rest | silent 2 beats | 2 |
| Quarter rest | silent 1 beat | 1 |

Worked example: One measure of "quarter, quarter, half" is ta | ta | ta-ta (held) = 1 + 1 + 2 = 4 beats. That is a complete measure.

Questions

1. How many beats does a half note get in 4/4? ______________________

2. How many beats does a whole rest get in 4/4? ______________________

3. Count the beats: ta | ta | ta | ta. How many beats total? ______________________

4. Is the measure "half note, quarter note, quarter note" complete in 4/4? Explain with the beat count. ____________________________________________________

5. Fill in the missing rest: ta | ta | [quarter rest] | ta. How many beats does the rest need? ______________________

6. Write (in syllables) a measure of 4/4 made of two half notes. ______________________

7. Write (in syllables) a measure of 4/4 that uses four eighth notes. ______________________

8. Circle the measure that is NOT a complete 4/4 measure:
   a. quarter, quarter, half
   b. half, half
   c. quarter, eighth, eighth, half, quarter
   d. whole note
   Explain why the one you circled is wrong. ____________________________________________________

9. Write a 4/4 measure that contains one half note, one quarter rest, and quarter notes to complete the beats. Write it in syllables and show the beat count. ____________________________________________________

10. Challenge: Write two complete 4/4 measures, using at least one half note, one eighth-note pair, and one rest in your rhythm. Show the beat count for each measure. ____________________________________________________

## Answer Key

1. 2 beats.
2. 4 beats.
3. 4 beats (1 + 1 + 1 + 1).
4. No. Half note (2) + quarter (1) + quarter (1) = 4 beats. Yes, it is complete. (Correct answer: yes, the measure is complete, with 4 beats.)
5. 1 beat (a quarter rest). Check: 1 + 1 + 1 + 1 = 4.
6. Example: ta-ta (held) | ta-ta (held). Beats: 2 + 2 = 4.
7. Example: ti-ti | ti-ti | ti-ti | ti-ti. Beats: 1/2 + 1/2 + 1/2 + 1/2 + 1/2 + 1/2 + 1/2 + 1/2 = 4 total. (Note: each eighth note is 1/2 beat, so eight eighth notes make 4 beats. Students may write eight "ti" syllables, for example: ti-ti-ti-ti-ti-ti-ti-ti, which is also correct.)
8. Answer: b. Half + half = 2 + 2 = 4, which is complete, so b is actually correct. The incomplete measure is d, "whole note" is 4 beats and complete, so check the list again: a = 4, b = 4, c = 1 + 1/2 + 1/2 + 2 + 1 = 5, d = 4. The measure that is NOT complete is c, which has 5 beats. Circle c. Reason: it adds up to 5 beats, one more than the 4 beats a 4/4 measure holds.
9. Example: ta-ta (held) | quarter rest, ta, ta. Beats: 2 + 1 + 1 = 4. Also accept any arrangement that totals 4 beats with one half note, one quarter rest, and quarter notes.
10. Example: Measure 1: ta-ta (held) | ti-ti | ti-ti | quarter rest. Beats: 2 + 1/2 + 1/2 + 1 = 4. Measure 2: ta | ti-ti | ti-ti | ta | ta. Beats: 1 + 1/2 + 1/2 + 1 + 1 = 4 would need checking; a correct version is: ta | ti-ti | ti-ti | half note (ta-ta). Beats: 1 + 1/2 + 1/2 + 2 = 4. Accept any two measures that each total 4 beats and include the required elements.
